# Moe Kyaw Aung Portfolio

A production-ready personal portfolio website for Moe Kyaw Aung, a Senior Android Developer and Software Engineer.

The website presents Android projects, full-stack projects, technical skills, professional experience, education, certifications, publications, awards, testimonials, services, contact information, and engineering articles.

## Live Website

[Visit the portfolio](https://moekyaw.dev)

## Preview

![Portfolio preview](public/og-image.svg)

## Features

- React 18
- Vite 6
- Tailwind CSS
- React Router
- Responsive design
- Dark-mode interface
- Accessible semantic HTML
- Keyboard-friendly navigation
- Mobile navigation menu
- Lazy-loaded routes
- SEO metadata with React Helmet Async
- Vercel SPA deployment configuration
- Modular component architecture
- Reduced-motion support
- Optimized production builds

## Technology Stack

## Installation
Clone the repository:
```
git clone https://github.com/Dev-moe-kyawaung/React18-Vite6-Tailwind-CSS-portfolio/
cd React18-Vite6-Tailwind-CSS-portfolio
```
## Install dependencies:
```
npm install
```
